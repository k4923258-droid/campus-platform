# v0.5 实现与测试记录

本次在本地完成账号核验与团队权限改造。此前的实现前复核保留在《v0.5项目复核与改造方案-2026-11-01.md》；本记录说明本次源码与实际检查结果。线上网站未部署，需求Word与PPT未改写。

账号增加邮箱验证、可信学号绑定、身份来源、账号状态和会话安全版本；正式模式关闭旧免验证注册入口。团队成员以用户ID建立关联，学号用于可信映射、检索、展示与活动内唯一性检查。报名、查看、附件、通知和退出按已保存的用户ID判断，补核验不自动接管历史团队。

已实现验证码注册、密码恢复、补核验、邮箱换绑、管理员身份冲突处理、成员核验预览及学校认证预留入口。新密码使用带随机盐的PBKDF2-HMAC-SHA256（600000次），支持完整8～128字符；旧BCrypt仅兼容校验，不接受超出其字节限制的输入。学校认证始终显示未接入，不能由客户端参数建立学校认证状态。

验证码绑定申请、邮箱与用途，5分钟、一次性、最多失败5次、重发60秒；数据库保存带服务端密钥的摘要。失败次数独立落库，恢复成功撤销全部既有会话。身份唯一性、活动成员占用及预约在MySQL事务与唯一约束下检查。新旧正式认证来源可共同组队，演示身份与正式身份不混用；成员停用后无法自动通过或发布录取。
