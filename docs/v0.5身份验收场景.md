# v0.5 身份专项验收场景

以下保留18个身份场景。本地执行范围见《v0.5实现与测试记录》与artifacts/v05-*.json；真实校邮与学校认证接入不计作已完成。

## TC-ID-001　白名单

预期：相似域名、额外子域、neu.edu.cn.evil.example或仅以.edu.cn结尾的其他地址，均不能完成校邮注册。

关联：REQ-F-101、REQ-N-071

实际结果：本地模拟、Java规则或MySQL/SMTP对应检查通过；真实校邮环境未执行，详见实现与测试记录。

## TC-ID-002　正式注册

关联：REQ-F-010、REQ-F-102、REQ-F-103

实际结果：本地模拟、Java规则或MySQL/SMTP对应检查通过；真实校邮环境未执行，详见实现与测试记录。

实际结果：本地并发注册、身份唯一约束及未映射域名不激活检查通过；真实跨域映射待官方规则确认。
