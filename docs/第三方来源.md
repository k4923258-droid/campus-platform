# 第三方来源与采用说明

项目由 create-vue 3.24.0 生成基础工程。业务规则与页面为本项目编写。未复制 Pure Admin、FormCreate 或 Sports Club Manager 的源码；这些仓库仅用于比较布局、表单描述方式及功能组织，不对其运行可靠性作背书。

| 参考                | 采用范围               | 版本或来源                                        |
| ------------------- | ---------------------- | ------------------------------------------------- |
| create-vue          | 项目基础工程           | 3.24.0 / https://github.com/vuejs/create-vue      |
| Pure Admin Thin     | 管理页面组织思路       | https://github.com/pure-admin/pure-admin-thin     |
| FormCreate          | 字段描述与渲染分离思路 | https://github.com/xaboy/form-create              |
| Sports Club Manager | 预约与会员端功能比较   | https://github.com/JosephHu04/sports-club-manager |
