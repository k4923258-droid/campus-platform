# 前端参考与改版

本轮针对信息呈现和文案修改，不增加业务流程。没有复制参考站点的源代码、校徽、图片或公告。

| 公开页面                                                                                                    | 实际查看的界面                         | 采用的做法                                                 |
| ----------------------------------------------------------------------------------------------------------- | -------------------------------------- | ---------------------------------------------------------- |
| [Ohio State 学生组织目录](https://activities.osu.edu/involvement/student-organizations/find-a-student-org/) | 学校站点导航、组织查询、基础及高级筛选 | 区分服务导航与查询内容，使用克制的红色强调                 |

参考页面已通过独立浏览器实际打开并保存截图：`artifacts/reference-osu.png`、`reference-cornell.png`、`reference-usu.png`。Kimi扩展当时未连接，未冒充通过该扩展完成检查。

移动端收起侧栏筛选，保留搜索和板块入口，活动行按窄屏重新排列。业务路由、报名、审核、面试与录取接口沿用原实现。
